## Context

动机与交付边界见 [proposal.md](proposal.md)。本设计来自本次仓库阅读与 Unity 只读检查，不是功能修复或运行验收记录。

### Conflicts to replace explicitly

- 主 `character-controller` 仍要求手写脊椎旋转、固定基础状态拓扑/播放速度/过渡、MoveX/Y 直接指向特定 clip；`player-input-model` 仍要求 LateUpdate 回转与进入瞄准瞬时 snap。这些实现约束由本 change 的完整 MODIFIED 块替代，原有行为场景保留并更新预期。
- 旧 IK delta 未生效，不据它直接添加第二份主规格。本 change 用新的枪口与手臂能力承接其枪口跟随、平滑进入退出、死区内上身跟随和大幅转身目标。
- 旧文档的“Offset 非同步属性”与安装包 1.3.1 的 `SyncSceneToStream`/job 读取不符；“Priority 不重排”与 Cinemachine 2.10.3 的 Update 检测不符。旧记录保留，当前文档另行说明纠正和实测结果。
- 旧规格写 ±50°，当前相机实际限制是 Euler pitch [-30°,70°]（上仰 30°、下俯 70°）。本次以当前可操作范围完整验收，不缩小范围来掩盖失效。

## Goals / Non-Goals

**Goals:**
- 每项最终姿态只有一个写入者，几何目标与动画表现使用同一帧数据。
- 在当前角色/武器范围内形成可测量、可回归的完整移动瞄准交付，所有定向疑点在完成前闭环。
- 维持现有业务输入、QFramework 边界、CharacterController 碰撞与跳跃语义，复用已安装资源。

**Non-Goals:**
- 不建设通用多武器/多角色框架；输出类型只保留必要的数据与失效状态。
- 不迁入 Core，不改变卡牌/伤害接口，不借此重构无关业务或音频模块。产品层排除项见 proposal。

## Decisions

### D1 — One movement and facing owner

在 `_Project` 建立项目运动适配实现，依据当前 StarterAssets 控制器制作可追溯的项目副本，记录来源版本与差异。保留其重力、Grounded、跳跃消耗、胶囊位移和速度行为，仅拆分输入缓冲、运动朝向、瞄准朝向和相机意图更新。旧供应商 TPC 不与项目副本同时启用；供应商文件不改。

采用项目副本是因为当前关键 Move/CameraRotation 为私有流程，不能靠继承重写少量方法获得正确时序。拒绝再增加一个 LateUpdate 覆盖者；不重写完整物理控制器。SAInputAdapter 的缓冲契约保留或适配为等价接口，测试跟随契约更新，不能把实际运动验证降为仅检查 Model 值。

非瞄准时仍面向运动方向；瞄准时位移与身体 Yaw 解耦，身体朝向在动画求值前确定。静止小幅转视角允许上身领先，超阈值带转身动作追随。初始调校采用 15° 起转/5° 停转的迟滞、360°/s 静止追随速度；稳定瞄准残余身体 Yaw 误差上限 35°。进入瞄准使用独立的约 0.3s 最短路径平滑对齐，不受静止追随角速度限制，以覆盖初始 180° 差值和 0.35s 收敛要求，不保留突兀 snap。这些是工程默认值，允许在不降低规格验收标准的前提下调校并记录。

### D2 — Directional locomotion separated from holding pose

项目 Animator 拆分非瞄准运动、瞄准方向运动与空中/落地表现，并使上半身基础持枪姿态与最终武器对准解耦。基础站立/走跑和已有跳跃素材优先复用；允许调整项目状态机、Mask、BlendTree、过渡和播放速率，不再受“与原 SA 完全一致”约束。

运动参数由当前实际平面速度转换到身体局部坐标，处理加减速、阻挡、方向切换与斜向归一化。不得仅凭按键或素材文件名指定动作。先采样 F/B、两组左右步态、AimJog、转身与跳跃素材，记录真实方向、触地相位、重定向和根运动设置，再构造八方向混合与速度匹配。根运动不成为第二个位移来源。

2026-09-18 用户实测补充：非瞄准奔跑枪穿入身体、举枪静止/移动切换僵硬、举枪快跑仅加速走路不自然。以下三项纳入本 change 的修正与最终复验，不构成阶段验收通过。

瞄准运动参数采用带配置化阻尼的实际局部速度，幅度从 0 连续增长到步行阈值；不得一有位移就归一化为满幅方向。站立/移动、走/跑、换向都保持连续混合与步态相位，姿态过渡不得通过重开枪口 Transition 豁免误差。

瞄准只允许纯向前奔跑（Move.y > 0 且 Move.x 为零，数值容差仅用于浮点零）。A/S/D 及任何带侧向分量的组合（包括 W+A、W+D）即使保持 Shift 也按走速；松回纯 W 自动恢复奔跑，非瞄准奔跑保持原规则。原始 Sprint 输入不清除。PlayerSystem 通过只读 Query 决定奔跑许可，PlayerMotor 在同帧限制实际水平速度，表现层读取本帧结果选择步态。

方向不允许奔跑时立即将实际速度封顶为 WalkSpeed，且动画 Gait 归零；移动方向参数继续平滑混合。正向步态可混合 AimWalk_F / 普通 Run，其余方向只接走路，移除 Run_45…315 的生产引用。空中方向变化与进入/退出瞄准也遵循同一许可，不改跳跃物理。旧方向跑素材保留为未采用实验记录，不能由配置入口重新挂回。

### D3 — Weapon pose drives both grips

在项目角色/武器资产上标定独立 AimPivot、Muzzle、RightGrip、LeftGrip 和肘部 Hint。Muzzle 的位置取实际枪口中心，+Z 沿真实枪管；使用正交侧视/顶视和枪管延长线验证，不能以 hand_r.forward 或网格包围盒最长轴代替最终标定。

先取得本帧基础动画姿态，再计算武器目标。非瞄准时武器跟随本帧基础动画的持枪手，不能使用根空间固定低持枪位置覆盖奔跑手臂；进入/退出瞄准时在该基础姿态与精确瞄准姿态之间连续混合。读取的是本帧约束前的动画手部，不是上一帧已经受 IK 控制的最终手部，因此不形成回读循环。

瞄准系统确定独立武器目标姿态；双手 Two Bone IK 对齐该姿态下的握把，躯干只提供自然的有限俯仰/扭转。手部目标与实体握把标记分开：非瞄准目标保持基础手/肘姿态；瞄准时收敛至握把与校准肘 Hint。武器支点以本帧基础肩部位置为参照，避免普通奔跑的身体起伏把固定武器穿入躯干。武器目标由角色参考架、姿态配置和目标计算，不挂在受它控制的右手下面；握把和肘 Hint 不构成回读循环。允许一次性的物理坐标/中立姿态标定，不允许用站立/各方向独立补偿掩盖运动误差。

在项目实例/Variant 中替换冲突的供应商武器重挂脚本、ParentConstraint 和旧三脊椎瞄准配置；不能在原父约束仍写枪时叠加另一套武器控制。旧 SwitchSocket 事件由项目兼容接收器安全处理，不触发供应商重挂。本次固定一把武器，不实现收枪/换枪。

### D4 — Aim geometry and obstruction

从完成碰撞与镜头混合的实际渲染相机屏幕中心构造射线：命中最近有效环境/目标表面则取命中点，无命中则取配置远点，默认 200m。忽略自身碰撞体、诊断对象和触发器；相机过滤与枪口过滤分别配置，但均覆盖验收环境。

武器姿态求解必须计入枪口相对 AimPivot 的位置偏移，使最终 `Muzzle.forward` 指向中心目标；不能直接复制 Camera.forward，也不能用上一帧枪口构造本帧固定 LookRotation 后就声称已对齐。使用确定性几何求解（计入旋转后枪口位置），并通过最终枪口采样复核。

从最终枪口到期望目标再检查遮挡，保留 DesiredTarget 和实际 ObstructionPoint 两个不同概念。枪口被挡时不把墙后的目标发布为可直射；目标位于枪口后、处于不可达近距、射线起点在障碍内或握把超出可达范围时给出明确安全状态。禁止以标记无效绕过正常矩阵：3/10/50/200m无遮挡目标、完整允许俯仰和当前允许的正常走跑跳都必须有效。

无限远同一消失点是极限情况；有限距离以共同目标点对齐。诊断同时显示相机中心线、枪管延长线、目标与遮挡，不实现子弹或伤害。

### D5 — QFramework ownership and output contract

以下名称是本变更拟新增/适配的 Unity 类型，不是已有 API。

| 层 | 所有权与职责 |
| --- | --- |
| 既有 PlayerInputModel / PlayerSystem | 继续保存业务输入与瞄准状态；不把场景对象、相机 Look 或骨骼写入 Model。 |
| AimModel | 保存当前场景会话的不可变瞄准数据快照、帧号、有效性；只含值数据，不持有 Transform/Camera/Collider。 |
| IAimSystem / AimSystem | 校验采样与配置、计算几何/遮挡状态、接受最终姿态采样并发布结果；通过接口调用物理查询 Utility，不持有场景 MonoBehaviour。 |
| IAimWorldQuery / Unity Utility | 提供射线与必要起点重叠检查，返回命中点/法线等值；生命周期释放，不使用全局查找定位场景服务。 |
| Commands / Query | 提交本帧相机/角色采样、最终枪口采样及失效意图；Command 无返回值且委托 System。Query 只读取解算目标或已发布快照，不求值动画、不射线、不发事件。 |
| Controller / View | 输入适配、运动与相机调度、角色/武器/双手场景绑定；表现组件使用显式引用，由一个协调者安排顺序，不互相拼接业务。 |

GameApp 按 Model → Utility → System 注册。快照至少包含 SceneGeneration、FrameId、Status、MuzzlePosition、BarrelDirection、DesiredTarget、HasObstruction、ObstructionPoint（仅有遮挡时有效）、AimErrorDegrees；Status 区分 Inactive、Transition、Ready、Blocked、Invalid。已知名称在实施时一次性定稿并同步文档，不形成多份权威状态。

Ready 必须来自本帧最终枪口，过期帧或场景代际不匹配按无效读取；失焦/停用/销毁时立即失效。后续射击直接读取这一份结果，本次 Fire 仍只记录输入。中间解算目标与最终对外快照分开，不用“期望方向”冒充实际枪管方向。

### D6 — Explicit evaluation schedule

选用一个项目表现协调者明确调度，基础动画和约束保留在同一个手动图中，以保证 PreviousInputs 在图内共享正确的 humanoid 姿态。第一遍关闭双臂约束并只推进一次 dt，取得躯干校正后的手/肩姿态；更新目标后第二遍以零时间步应用约束，不再次推进状态时间。这样可以在基础姿态与最终 IK 之间取得真实持枪手/肩部姿态。顺序为：

```text
Input sample --> Motor movement + body yaw --> Camera orbit intent
--> Final camera (blend + collision) --> Base animation (advance dt once)
--> Torso assist --> Sample pre-arm-IK hands / shoulders --> Aim geometry / weapon / hand targets
--> Torso + arm constraints (evaluate once, no time advance)
--> Final muzzle + grip sampling --> Publish current-frame aim snapshot
```

相机跟随根参考架而非由手臂 IK 反向驱动的骨骼；Look 仍是一个表现输入路由。该图由同一协调者持有，两遍求值但每帧只推进一次时间，各阶段只有一种求值所有权，禁止自动和手动双跑；记录基础图求值前后及约束图前后的状态时间，证明约束求值不再次推进动画。RigBuilder/Animator 的图连接及时间推进按实际 1.3.1 API 验证。必须先做小范围运行验证，记录输入帧、相机帧、求值计数和最终枪口帧，并覆盖动画事件、布料、30/60/120fps；不能仅配置 DefaultExecutionOrder 后跳过证据。

如果 Unity 的外部图/PreviousInputs 语义需要改变调度细节，先更新本节与对应任务，再实现；必须仍满足相同的单帧、单次时间推进与输出契约。这是 API 适配验证，不是把架构方向留到实现者任意选择。

### D7 — Transitions, lifecycle and camera safety

稳定输入后默认在 0.35s 内完成进/出瞄准和状态收敛；按同一目标状态协调持枪/躯干权重及相机混合。切换中快照为 Transition，不承诺非瞄准低持枪姿态立刻对准；连续切换从当前姿态衔接，不能排队播放过期过渡。身体大角度差不以瞬间 snap 消除。

表现绑定成功后先读取当前状态，再订阅增量；禁用退订并清理自己的镜头/权重/快照，重新启用恢复当前值。配置缺失时一次性给出具体错误并安全失效，不隐式创建架构。输入恢复已解决的 Jump/Fire 释放重按规则不变。

瞄准和普通相机均参与环境碰撞；从包实际优先级机制出发移除未经证明必要的 disable/enable 补丁，实测快速切换和平滑。检查 Animator 的 CullUpdateTransforms 对离屏/近墙遮挡时枪口更新的影响；本地玩家如因剔除导致求值停滞，采用持续求值并验证，不允许发布旧枪口快照。

### D8 — Audio and residual cleanup

保留现有两个 AudioSource 和音频资源，通过当前有效运动相位/接地状态驱动脚步和落地。增加项目配置映射/相位曲线以支持方向混合；不依赖某一 clip 必须占权重一半，不在空中或停住时继续出步声，落地只触发一次。运行时按实测动作相位标定，音频只是适配变化后的表现，不扩展枪声/UI音。

旧 Geometry 的禁用回退对象保留；不可达 Fly 等残留只在确认引用后随相关 Animator 整理，不能无差别删除。QFrameworkValidator 从交付场景移到显式验证入口/独立测试场景，避免启动时写 HP；不借此重构 HP 业务。所有新增测试/诊断限定 Editor 或测试程序集，运行时不得引用它们，取消/失败也能清理临时对象和设置。

### D9 — Evidence and acceptance

量化阈值是本提案选定的工程验收值，不是历史测量结果：

- 在无遮挡、可达且 Ready 的稳定采样中，实际枪管轴线对 DesiredTarget 的角误差 ≤0.1°；30/60/120fps、连续相机转动 ≤180°/s 及运动/落地切换时 Ready 样本最大误差 ≤0.5°，不能用均值隐藏峰值。
- 对外 BarrelDirection 与实际 Muzzle.forward 误差 ≤0.05°，且帧号一致；双手到握把的位置误差 ≤1cm、旋转误差 ≤2°（Ready 稳定/运动矩阵均测）。
- 初始稳定收敛窗口 ≤0.35s；持续有效瞄准的普通走跑跳/方向切换不重新开启 Transition 来豁免误差。极近不可达/起点重叠用独立边界用例验证，不计成正常通过样本。
- 目标距离 3、10、50、200m及无命中远点；俯仰 Euler -30、0、35、70°；静止、八方向行走及纯向前奔跑（其余方向按住 Shift 也走路）；原地跳与八方向移动跳、落地；每个循环动作至少覆盖完整周期并记录最大值。主要矩阵在 60fps，30/120fps 复跑各动作/边界类别及误差最差组合。
- 补充左右转身、视角跨 ±180°、快速切换瞄准、近墙转角、相机被推近、武器被挡、目标进入近距/消失、配置错误、三次组件启停、首次按住右键启用、真实失焦恢复、两次独立 Play/Stop及保存重载。
- 录像/人工观察检查侧扭、肩腕/肘变形、双手脱枪、腿步方向、滑步、跳落衔接、布料和脚步听感；用户对范围内视觉和手感明确认可，最终复验必须包含本轮提出的非瞄准奔跑持枪、站立/移动混合、真实快跑下半身三项。量化成功不能替代该项。
- 本次重跑输入回归：原 150 断言覆盖的输入、错误配置、生命周期与真实运动消费语义保留，必要适配测试夹具；报告新次数和结果，不要求机械保留旧数字。

## Risks / Trade-offs

- [高速侧移素材不自然] → 在全量接线前完成方向/速度素材验证；项目副本调整/组合，仍失败则阻塞交付，不能跳过高速方向。
- [枪目标固定造成手臂不可达] → 姿态配置包含肩部/武器位置与肘 Hint，按允许俯仰和距离验证；不把正常矩阵误标 Invalid。
- [手动求值影响事件、布料或帧序] → 首先验证唯一图/每帧求值与布料时序，之后才扩展场景；数据测量与视觉回归均必需。
- [从右手挂枪改为独立武器目标] → 项目 Variant 替换旧写入者并检查所有引用，保留供应商源资产与原回退外观。
- [音频规格与简化文档数据流不一致] → 以当前实际相位播放为起点，保持音频外部契约并更正共享文档，不额外建设全项目音频总线。
- [量化/观感标准未达到] → 本 change 保持未完成；若确需产品范围或采购变更，单独说明并由用户决定，不通过放宽测试来收口。

用户在最终观感复验中否定侧向/后退快跑并明确授权以上限制；本次是产品范围修订，替代原“八方向均可举枪跑/不得禁跑”的约束，不是把失败项暗中记为通过。旧报告按旧规则保留，追加前向奔跑许可、同帧限速、动画引用及持续 Shift 换向专项。


### D10 — Jump pose synchronized to vertical motion

用户复验确认“先弹起再收腿”。60fps 基线：起跳帧角色根已升约 0.10m，但腿仍是地面姿态；约 0.10s 收腿后，又在约 0.16s 从 AirR 切到 AirL 起始段，右膝从约 131°弯曲回到约 17°。音频仅观察接地，不驱动该时序。

保留即时跳跃、JumpHeight=1.2、Gravity=-15、输入边沿和实际落地音。改用同一项目 AirR clip 的连续空中段，JumpStart / InAir 共用物理相位参数：上升从起手相位 0.15 到顶点 0.40，下降到预落地 0.90；相位依据 Motor 提供的竖直速度/起跳速度，落地时冻结在预落地相位。走下平台时使用后段落姿，不重播起跳。数据采样显示这些区段包含收腿、保持和伸腿，不再从相反腿的 clip 开头重播。

JumpTriggered 由表现协调者在本帧显式触发短 CrossFade，再推进一次 dt，使第一帧即参与起跳混合；移除旧 Animator Jump 布尔过渡，避免二次进入。JumpStart 在顶点转入 InAir，两状态使用同一相位，实际 Grounded 随时可进入 Land。配置集中在 PlayerAimProfile；动画/音频不反向改变物理。固定侧视录像与逐帧膝角/脚高验证同步改善，同时复验原地、走跑/侧移、举枪/非举枪、帧率和落地单次音效。
