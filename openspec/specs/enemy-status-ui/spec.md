# enemy-status-ui Specification

## Purpose

为真实敌人提供与其身份和当前权威状态一致的头顶生命条及防护状态提示，使玩家能够辨认射击的实际结果、剩余减伤和额外易伤，并在遮挡、死亡及重新注册时正确隐藏或恢复。

## Requirements

### Requirement: 生命条与防护提示反映当前权威状态

每个已注册且存活目标 SHALL 显示属于自身的生命条，以当前 HP/最大 HP 表示填充比例。状态提示 SHALL 使用剩余减伤率 `R * (1 - clamp(H, 0, 1))` 和额外易伤率 `max(H - 1, 0)`：有剩余减伤时显示减伤百分比，无减伤也无增伤时显示无减伤，H>1 时显示额外易伤百分比。显示 SHALL 区分易伤增加量与总伤害倍率，不把原始 H 当作减伤率或独立可消耗护盾值。

#### Scenario: 防护语义表
- **WHEN** R=0.95，H 依次为 0、0.5、1、1.2、1.6
- **THEN** 状态 SHALL 分别表达减伤 95%、减伤 47.5%、无减伤、易伤 +20%、易伤 +60%，不显示负减伤或“120% 易伤”；百分比最多保留一位小数

#### Scenario: 扣血与零扣血
- **WHEN** HP 从 100 降至 75，随后发生零实际扣血命中
- **THEN** 血条填充 SHALL 更新至 0.75 并在零扣血后保持；UI 不得自行扣血、治疗或改写目标配置

### Requirement: UI 在目标身份和状态变化后及时同步

UI SHALL 从当前只读快照初始化，并在实际扣血、H 更新、注册或注销之后最迟于下一次渲染呈现正确状态。不同目标 SHALL 不共享显示缓存；目标死亡或身份失效 SHALL 隐藏 UI。UI 恢复或目标重置 SHALL 读取现状，不补播旧变化或保留旧身份数据。

#### Scenario: 单目标系数覆盖
- **WHEN** 显式命令只把目标 A 的 H 从 0.5 覆盖为 1.2
- **THEN** A 的提示 SHALL 从减伤 47.5% 切到易伤 +20%，HP 不变；目标 B 的血条和提示保持原值

#### Scenario: UI 晚启用及死亡期间重置
- **WHEN** UI 在目标受伤后启用，或死亡目标重新注册后 UI 恢复
- **THEN** SHALL 分别显示当前受伤快照或新身份的初始快照；旧死亡/系数事件不得修改新目标显示

### Requirement: 头顶 UI 跟随镜头并尊重遮挡

UI SHALL 锚定目标上方并朝玩家可读方向呈现，在非瞄准和瞄准状态下均可显示；处于相机后方、视口外、超出配置显示距离或被实心环境遮挡的目标 SHALL 隐藏 UI。UI SHALL 不拦截射线、移动或现有输入，也不将隐藏信息压到屏幕边缘作为指示箭头。

#### Scenario: 镜头转动与距离变化
- **WHEN** 玩家围绕存活目标转动相机、进出瞄准并走到显示距离外
- **THEN** UI SHALL 保持锚定和可读，超范围或出视口时隐藏，重新满足可见条件后恢复当前状态；不会留在旧屏幕位置

#### Scenario: 墙后与透明触发区域
- **WHEN** 不透明实心墙挡住相机到 UI 锚点的视线，或该路径仅穿过玩家自身、目标自身及 Trigger
- **THEN** 墙后 UI SHALL 隐藏；仅被自身或 Trigger 覆盖时不误隐藏，碰撞查询不会改变业务命中结果

### Requirement: UI 缺项与停用不影响战斗结算

缺少相机、锚点、必要显示引用或合法参数时，UI SHALL 安全隐藏并给出每次启用至多一次的具体诊断；HP、H、碰撞和射击伤害仍按原业务执行。禁用/销毁和场景退出 SHALL 释放该视图的订阅与显示对象，不在清理期间创建业务架构。

#### Scenario: 缺引用后修复
- **WHEN** UI 缺失相机引用，玩家仍对目标射击，随后修复引用并重新启用 UI
- **THEN** 伤害 SHALL 正常结算且无空引用刷错；UI 恢复后显示当时的真实 HP，既不重置敌人也不补算伤害

#### Scenario: 多次启停与场景退出
- **WHEN** UI 连续启停三次并退出场景
- **THEN** SHALL 无重复显示、重复订阅、残留血条或清理引起的架构重建；表现错误不能被当作可验收配置
